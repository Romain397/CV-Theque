# 🎓 CVthèque - Frontend React

**Application de gestion d'étudiants avec API REST**

---

## ⚡ Démarrage RAPIDE (3 minutes)

```bash
npm install        # 1. Installer (une seule fois)
npm run dev        # 2. Démarrer
```

Ouvrir: **http://localhost:5173** ✅
